TerraScope — Earth Intelligence Web UI
A responsive frontend starter for your Earth Science research platform.
Files
index.html — page structure and dashboard sections
style.css — responsive visual design
script.js — small UI interactions (form feedback, mobile navigation)
Run locally
Open index.html in a browser. No build tools are required.
Upload to GitHub Pages
Create/open your GitHub repository.
Upload index.html, style.css, and script.js to the repository root.
Commit the changes.
In Settings → Pages, choose Deploy from a branch, select main and / (root), then Save.
Open the GitHub Pages URL after deployment finishes.
Important
This is a frontend design prototype. The map, metrics, activity, source status and research results are illustrative sample UI, not live scientific data. The form currently shows a demo confirmation only. Real NASA/Copernicus/CHIRPS data collection, Python analysis, database storage, maps and reports require a backend and provider-specific API/data integrations. Do not put private API keys in frontend JavaScript.
